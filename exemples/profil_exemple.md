- **Attaques secondaires** : ko-uchi-gari, de-ashi-barai
- **Enchaînements** : ko-uchi-gari → uchi-mata | o-uchi-gari → o-soto-gari
- **Contres** : uchi-mata-sukashi
- **Garde préférée** : classique main droite revers, main gauche manche

- **Transitions** : après attaque ratée → contrôle tortue
